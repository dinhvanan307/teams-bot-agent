# Báo cáo gói 1

Báo cáo PDF ghi nhận code baseline 39ad99d0931b2ba38d00129b636b1cff5495e59f, kết quả kiểm thử và kế hoạch tích hợp. Các commit hồ sơ sau baseline không thay đổi source runtime đã kiểm thử.

Tạo lại bằng tools/build_package1_report.py với Python và ReportLab. Đặt REPORT_FONT_DIR tới thư mục có NotoSans-Regular.ttf và NotoSans-Bold.ttf nếu không dùng runtime Codex trên máy lập báo cáo. Dữ liệu lấy từ docs/evidence/. Sau khi render cần kiểm tra bố cục từng trang.
